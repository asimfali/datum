---
name: pr
description: Открывает pull request Datum по текущей задаче. Используй по команде «PR» или по просьбе открыть pull request.
---

Подготовь имя ветки из темы задачи, заголовок на английском и файл описания на русском по [шаблону PR](../../../.github/pull_request_template.md). Обнови `HANDOFF.md` по правилам `AGENTS.md`, если состояние задачи ещё там не отражено.

Из корня репозитория запусти `bash scripts/pr.sh <branch> <title> <body-file> [-- <path>...]`. Для незакоммиченных правок перечисли после `--` конкретные пути текущей задачи, включая `HANDOFF.md`, если он обновлён для неё. Если нужные изменения уже в коммитах, опусти `--` и пути. Скрипт выполняет операции Git, проверки и публикацию PR.
