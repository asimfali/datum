# Datum

[English](README.md) | **Русский**

**Design Automation Toolkit for Universal Modeling**
<br><sub>под капотом: *Distributed Architecture for Topology-based Unified Modeling*</sub>

Параметрическое твердотельное ядро, написанное с нуля на Rust, которое использует **все ядра процессора** и при этом остаётся **побитово детерминированным**.

> **Статус:** proof of concept завершён (M0–M5). Теперь Datum растёт в открытую CAD-систему, начиная с листового металла. Для ежедневной работы он пока не готов: модели строятся как JSON-графы операций (вручную, скриптом или ИИ-агентом через MCP), а во вьюере их параметры правятся с живым пересчётом.

## Зачем

Массовые машиностроительные CAD перестраивают модели в один поток. Их ядра и деревья построения спроектированы десятилетия назад вокруг изменяемого общего состояния и линейной истории. Инженеры платят за это каждый день: медленное перестроение, ссылки, которые рвутся после правки в начале истории, сбои, которые никто не может предсказать.

Datum исходит из других предпосылок:

- **Неизменяемые тела.** Операция никогда не меняет вход, она создаёт новое тело. Нетронутые части общие.
- **Граф зависимостей, а не список.** Независимые операции перестраиваются параллельно, пересчитывается только то, что действительно изменилось.
- **Стабильные имена топологии.** Каждая грань, ребро и вершина названы по происхождению («боковая грань выдавливания X от ребра эскиза Y»), а не по счётчику. Ссылки переживают правки, результат не зависит от числа потоков.
- **Символьные пересечения.** Булевы операции сопоставляют вершины пересечения по ключу, а не по допуску расстояния, поэтому грани режутся на разных ядрах независимо и сшиваются точно.
- **Нет «рабочей области».** Абсолютных допусков нет, поэтому нет и «куба в 1 км»: генплан и болт M6 живут в одной модели.
- **Создан для ИИ-агентов.** Каждая операция — JSON-команда со сгенерированной схемой; одни и те же команды у командной строки, окна и MCP-сервера. Модель хранится как JSON-граф операций, геометрия перестраивается детерминированно.
- **Честный отказ.** Неподдерживаемый вырожденный случай возвращает ошибку, а не правдоподобное, но неверное тело.

Долгосрочная цель — открытая CAD-система для инженеров-конструкторов, построенная вокруг того, что им действительно нужно.

## Что доказал proof of concept

| # | Утверждение | Результат (Ryzen 5 3600 под WSL, 6 логических ядер; 1 поток против 6) |
|---|---|---|
| C1 | Перестроение графа масштабируется по ядрам на «широких» моделях | 1000 независимых тел: 230 → 61 мс (×3,8) |
| C2 | Правка параметра в конце длинной истории мгновенна | правка последней из 200 операций: 0,14 мс сверх самой операции |
| C3 | Одна булева операция ускоряется внутри себя | пластина с 10 000 отверстий: 1,55 → 0,50 с (×3,1); рельеф из 10⁶ треугольников с котлованом: 3,38 → 1,28 с (×2,6); 10 000 отверстий в свальцованном листе: 432 → 172 мс (×2,5) |
| C4 | Результат побитово одинаков при любом числе потоков | хеши совпадают на 1/4/16 потоках и между Linux и Windows |

Координаты в 10⁷ м от начала (в миллиметрах) сохраняют всю топологию: рабочей области нет.

| Этап | Содержание |
|---|---|
| M0 | Основа: математика, B-rep на полурёбрах, примитивы, проверка тела, объём, канонический хеш, экспорт STL/OBJ, командная строка |
| M1 | Граф операций: мемоизация, ранняя отсечка, параллельный планировщик; JSON-формат модели; MCP-сервер; тесты детерминизма |
| M2 | Параллельные булевы операции над многогранниками |
| M3 | 2D-эскизы с решателем ограничений; выдавливание, вырез, массивы; параметры и выражения |
| M4 | Вьюер с живой правкой параметров; большие сцены на скромных видеокартах |
| M5 | Дуги и цилиндры; вырезы контурами эскиза; перфорация свальцованного листа в развёртке; развёртка как узел графа, экспорт DXF |

## Дорожная карта

Приоритеты задают реальные боли инженеров ([`PAINS.md`](PAINS.md)), а не паритет с коммерческими CAD. Полный план — в [`ROADMAP.md`](ROADMAP.md).

| Этап | Содержание |
|---|---|
| M6 | Листовой металл по эскизу-траектории: толщина, гибы в углах, вальцовка на дугах; точная развёртка; вырезы эскизом на любой грани, в том числе через гиб; DXF |
| M7 | Моделирование в окне: эскизы и операции создаются интерактивно; контекстные действия под курсором (грань → выдавить, ребро листа → фланец); формы команд и пользовательские макросы описаны в JSON |
| M8 | Операции листового металла: фланец по ребру, отбортовка, рельефы в углах, сгиб по линии эскиза, прорези для ручной гибки |
| M9 | Штамповка: нелинейная деформация листа как узел графа (МКЭ), развёртка с учётом утонения и пружинения |
| M10 | Надёжность правки: восстановление ссылок на реальных сценариях; булевы операции с кривыми гранями; компланарные случаи |

Дальше: агент как соинженер в окне (имена граней, подсветка в обе стороны, предложения правок с ревью); ассоциативные чертежи и спецификации по JSON-стандартам; сборки и исполнения; PDF-книга проекта; трассы проводов и труб; GLB для производства; скругления. Как Datum работает с инженером, агентом и документацией — в [`VISION.md`](VISION.md).

## Участие

Datum развивается открыто, и пригодится любая помощь:

- **Обратная связь** — что мешает вам в CAD каждый день и что вы хотели бы вместо этого. Реальные боли инженеров формируют план.
- **Звёзды** — они помогают другим инженерам найти проект.
- **Issues** — ошибки, модели, которые не перестраиваются, идеи.
- **Pull requests** — принимаются, если следуют принципам проекта (детерминизм, точные предикаты, никаких скрытых допусков; см. [`CLAUDE.md`](CLAUDE.md)). Для крупных изменений сначала откройте issue, чтобы обсудить подход.
- **Нестандартные идеи** — приветствуются. Сам Datum начался с сомнения в том, как обычно строят ядра CAD.

## Попробовать

Скачайте портативную сборку для Windows или Linux со страницы [Releases](https://github.com/asimfali/datum/releases), распакуйте куда угодно и запустите `datum`. Что попробовать и чего пока нет — [`TESTERS.md`](TESTERS.md).

Из исходников:

```bash
cargo run --release -p datum-cli -- examples/rolled_perforation.json   # вьюер с моделью
cargo run --release -p datum-cli -- dxf examples/rolled_perforation.json --out blank.dxf
cargo run --release -p datum-cli -- build tests/models/drilled_plate.json --out part.step
```

Вьюер открывает любую модель, перетащенную на окно; параметры правятся сбоку, модель перестраивается на лету. Модели для начала — в [`examples/`](examples) и [`tests/models/`](tests/models); формат — JSON-граф операций (`ARCHITECTURE.md`, §6).

## Разработка

```bash
scripts/check.sh   # fmt, clippy, тесты, проверка детерминизма
cargo run --release -p datum-cli -- build tests/models/bracket.json --out bracket.stl
cargo run --release -p datum-cli -- mcp   # MCP-сервер на stdio (.mcp.json регистрирует его для Claude Code)
```
