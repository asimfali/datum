## Задача

Копия и зеркало массива и удобства размеров (D285–D287) — сделано, ветка `feat/sketch-pattern-copy`, PR #277 готов к слиянию автором. D285: массив — полноправная часть копии, наработки и зеркала (`Pattern::references`, `extract` с `Selection`, `place` с переименованием ссылок, `mirrored` берёт массив с собой, `check` валидирует, `mirror::plan` — зеркальная группа и массив / переадресация). Доработки: рамка выделения берёт копии массива (`SketchEdit::framed`, `Pick::Copy`); круг без набранного размера сам открывает поле диаметра, Esc закрывает поле и заканчивает команду, круг остаётся; клик мышью тоже закрывает поле правки размера; подписи размеров попадаются с запасом и берутся раньше точек; двойной клик по кривой (и по копии массива) открывает её размер. Незакрытое: сквозной оконный тест на правку размера по кривой отсутствует (юнит-тесты есть).
Предыдущая: план библиотечной штамповки 0.5.6 влит ([PR #275](https://github.com/asimfali/datum/pull/275)), план: `status/stamp-component.md`; реализация не начата.
