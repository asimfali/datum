# HANDOFF — текущая задача

> Память между сессиями: только текущая задача. Потолок — 2k токенов. Долгие решения — `ARCHITECTURE.md` (D*), планы — `status/`.

## Задача

Библиотечная штамповка 0.5.6, первый язык на плоской стенке. План влит в PR #275, шаги в `status/stamp-component.md`. Автор открывает тестовые модели из `C:\develop\datum-test\Детали\`. Копировать туда эталоны для ручной проверки. Там же лежат исходный язык со скруглённым носиком и жалюзи.

## Состояние

- Прямой эталон `tests/models/stamp-tongue-straight.json` строит одну деталь и содержит узел `unfold`. Terra реализовала смещение профиля и сшивку в `crates/datum-ops/src/component/`; D288/D292: `component.part.forming` сшивает язык с выпуклой пластиной, `Formed` хранит предварительный рез, `unfold` и `Session::flat_of` выводят три свободные стороны.
- В D294 поле `round_section: true` включает касательные гибы у корня, полки и носика; эталон `stamp-tongue-rounded.json`. Толщина, внутренний радиус и K-фактор — из правила листа. Этап влит через PR #278.
- D295 влит через PR #279: «Кромка» на выпуклых прямых рёбрах между параллельными плоскими торцами, F открывает, Tab переключает фаску; носик языка и операция детали используют общий расчёт.
- Пробивка `cut` доступна с 0.5.5. Метаданные кривых и пресеты влиты в PR #274.
- D293 влита: единая память отдельных окон (положение, размер, развёрнутость по стабильным именам), два монитора с разным DPI, перенос старой записи «Правил».
- PR #280 (`feat/edge-sets`, D293/D296) открыт. «Кромка» опирается на подтверждённую сцену, включая соответствие меша входной операции. Предпросмотр показывает пробное тело, дерево сохраняет подтверждённую историю. Щелчок выбирает цель, Shift/Ctrl добавляет или исключает, Enter подтверждает один набор. Следующая операция строится от последней фичи тела; при правке выбирается входное тело редактируемой фичи.
- `edge_finish` объединяет `edge`, `edges`, `face` и `faces`, затем вычитает `exclude_edges`. Торец раскрывается в углы при перестроении, включая три оставшихся угла после одного скругления прямоугольного торца. Отложена оптимизация O(V·E) разворота торца, см. `status/edge-fillet.md`.
