## Решения

- Закоммичено и действует: D256–D258, D259, D260 (компонент-блок), D261 (жалюзи D261 — **концептуально отменяется**), D262 (контракт узла), D263 (база φ сферы по меридианам).
- Ядерные фиксы из задачи C остаются (проверены): ориентация `CurveSpec` (`put` с проверкой коллизий), `arc_between` (оси дуг из концов), выбор рабочей кривой (нормировка обхода), точки на оси без отдельных вершин, куски дуг ≥ π — отказ, D263, `with_louver` по ID граней.
- Отладочный приём (переиспользовать): жёсткая проверка спеков дуг в `attach_curves` (концы на окружности, `at(u,sweep)` = v, sweep < π) + печать плоской развёртки падающей грани — находит «комплементарные» дуги и несогласованные домены за минуты.
- Ревьюер по умолчанию — GLM-5.3-Flash (пул $60); DeepSeek V4 Pro — `reviewer-pro` по прямой просьбе.
- Профиль лепестка не подтверждён; лепесток отложен (планировка point в операции уже реализована).
