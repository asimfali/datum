# План: фланец с дотяжкой до грани ответной детали (D305)

> Кейс автора: `test9.json` — вертикальный лист и горизонтальная пластина (два элемента
> одного файла). Фланец на конце листа дотягивается до выбранной грани пластины с задаваемым
> зазором; угол выводится из грани — универсально для любого двугранного угла лист ↔ ответная
> деталь. Сейчас автор считает `height` руками. Задача на несколько сессий: таймбокс этапа
> ~1,5–2 ч, при перерасходе — стоп и обсуждение.

## Решение (D305, подтверждено автором 2026-11-26; уточнение семантики после первого ревью)

- `Flange.to_face: { face, from, gap }`: ID **плоской грани** тела-входа `from` и зазор ≥ 0.
- Выводятся **угол и поперечное положение**; **`height` — обязательный ввод, обычная высота
  D205 (квадратно листу)**; при выведенном не-прямом угле длина стены из неё следует
  (совпадает с ней при 90°; уточнение 2026-11-26 после ревью).
- В режиме один фланец на операцию: несколько `edges` → именованный отказ (сшивка углов не
  расширяем). `flip` выводится из грани, поле игнорируется.
- **`gap` — абсолютный**: наружная поверхность фланца ставится ровно на `gap` от плоскости
  грани, `gap = 0` — касание.
- **Положение гиба — из пересечения** (директива автора при приёмке 2026-11-26: «должно
  искаться пересечение и дотягиваться до граней»): линия плоскости наружной поверхности листа
  и плоскости грани, смещённой на `gap`. `D` — расстояние вдоль нормали торца (`out`) от торца
  до линии пересечения; `absolute = flush_recess(r,t,a) − D`: `absolute > 0` — подрезка торца
  (`recess_angle`, прежний путь, test10); `absolute < 0` — **удлинение** листа
  `ext = D − flush_recess` полосой за торец (`extended`: вершины торца на `out·ext`, грани
  растягиваются, ID сохраняются) и гиб на новой кромке. Случай «лист не достаёт до грани» —
  основной, не отказ. Единственный отказ: линия пересечения за дальним концом листа →
  `Degenerate`.
- **Угол всегда выводится из грани**: стена фланца ложится параллельно плоскости грани.
  Явный `angle ≠ 90°` в этом режиме — именованный отказ.
- **Сторона поворота** — к той стороне конца листа, где лежит грань; грань в плоскости листа
  (пересечения нет) → `Err(Degenerate)`, не приблизительный результат.
- Неплоская грань → `Unsupported` (паттерн `face_plane`); нет грани/тела → `LostReference`
  (паттерн `find_face`).
- Тело `from` — **вход фланца, не потребляется** (`users()` в `datum-graph` не считает его
  использованным, фикс приёмки): деталь-цель остаётся в сцене, STEP и продукте;
  параметрика — деталь переехала, фланец перестроился.
- `height_along` в режиме `to_face` не задаётся (именованный отказ); `to.top` — тоже.
- Отклонённый вариант — через рабочую плоскость на грани: `to.top` останавливает стену
  **вдоль** её хода (`Limit::bound` → `None` для плоскости вдоль стены), поперечный зазор
  между наружной поверхностью и гранью он не выражает; отдельный узел-плоскость — лишний
  посредник в дереве.

## Этап 1. Ядро: схема и разрешение to_face — готово

- [x] `Op::Flange`: `height` → `Option<Num>` (serde-совместимо), поле `to_face: Option<FaceTo>`,
      JsonSchema для формы view и MCP; валидация в `resolve`; вход-тело между `parts` файла
      разрешается (зондаж воркера на `test10.json`).
- [x] `flange.rs`: `dims_for_face` — вывод угла, стороны и поперечного положения из плоскости
      грани до построения стены; машина гибов/развёртки не тронута.
- [x] Правка по ревью (уточнение автора): `gap` — абсолютный (0 = касание, `shift = (d−gap)/(out·n)`,
      финальный клиренс ровно `gap`); `height` — обязательный ввод (обычная высота D205, квадратно
      листу); один фланец на операцию (несколько кромок — отказ); отказы `angle ≠ 90°`, `height_along`, `to.top`, закрытые углы, ширина не «по ребру»,
      зазор за кромкой / за дальним концом листа — именованные.

## Открытые вопросы

- Комбинация `to_face` с `to.start`/`to.end` (боковые плоскости стены): считать ортогональной,
  проверить тестом; если конфликтует — именованный отказ.
- Несколько `edges` в одной операции: `to_face` применяется к каждой; разные грани — отдельные
  операции (не расширять).
- Развёртка фланца с произвольным выведенным углом: ожидаем, что существующая машина D205/D229
  это покрывает; если нет — стоп и обсуждение до изобретения новых правил.
