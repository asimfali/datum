Loft 1 → 2 подключён. Стык торцов описан в D267, результаты проверок и шаги приёмки — в `HANDOFF.md`.

## Входы и контракт

- [x] Входы зафиксированы: A — одна линия; B — открытая цепь из двух отрезков с общей вершиной над серединой A. Числа раннего примера D265 не использовать для приёмки по обновлённому эталону автора.
- [x] Проверен эталон профилей автора `C:\develop\datum-test\Детали\loft(1 to 2 line)(2 stage).json` (WSL: `/mnt/c/develop/datum-test/Детали/`). `datum build` строит оба эскиза и плоскость. По решённым эскизам A = 100 мм, ноги B по 200 мм под 20° к горизонтали, расстояние между плоскостями 300 мм (`plane1.offset = -300`, нормаль −Y). У B `l1` и `l3` — профиль, `l2` — вспомогательная ось, единственная свободная степень эскиза — положение дальнего конца этой оси. Файл содержит профили; правило живёт в библиотеке проекта и назначается при добавлении лофта.
- [x] Контракт результата: три плоские треугольные фасеты (средняя — начало A, конец A, апекс — лежит в плоскости A; два крыла — конец A, апекс, конец B) и два цилиндрических гиба по линиям апекс→концы A с радиусом правила (не острые, D181) и K-фактором правила для развёртки.
- [x] Торец гиба у ребра A — квадратный срез толщины (гиб выходит на боковое ребро; ступень на углу автор подтвердил); толщина на стороне листа (`left`/`right`/`middle`), как в шаге 1.
- [x] Развёртка — через `unfold_side`: плоский веер с двумя гибами; у открытого `1 → 2` нет отдельного шва.
- [x] B — номинальный профиль. Прямые участки — монтажные кромки под сварку или фланец. У вершины B допустим местный зазор до ответной детали: не требуется укладывать весь торец в плоскость B. Это не разрешение на щель в самом листе, автоматическую разгрузку или перехлёст заготовки (D266).

## Отказы

- [x] Апекс на линии A (у средней фасеты нет площади) → `Degenerate`.
- [x] Нога B на линии гиба (у крыла нет площади) → `Degenerate` (фасета нулевой площади).
- [x] Касательные двух гибов не сходятся в общей точке или станции выходят за шарниры → `Degenerate`.
- [x] Профили вне случая (дуги, больше двух сегментов) → `Unsupported` с текстом; апекс не над серединой A → `Degenerate` (тест `two_line_loft_requires_the_vertex_over_the_first_line_midpoint`).
