# План: Loft, шаг 2 — одна линия → две наклонные (веер из апекса)

> Контракт подтверждён примером автора в Inventor 2026-11-17. Геометрия и
> сборка тела в коде, в `Op::Loft` ещё не подключены — идёт доводка
> (`HANDOFF.md`).

## Входы и контракт

- [x] Входы зафиксированы: A — одна линия; B — открытая цепь из двух отрезков с общей вершиной над серединой A. Числа раннего примера D265 не использовать для приёмки по обновлённому эталону автора.
- [x] Проверен эталон профилей автора `C:\develop\datum-test\Детали\loft(1 to 2 line)(2 stage).json` (WSL: `/mnt/c/develop/datum-test/Детали/`). `datum build` строит оба эскиза и плоскость. По решённым эскизам A = 100 мм, ноги B по 200 мм под 20° к горизонтали, расстояние между плоскостями 300 мм (`plane1.offset = -300`, нормаль −Y). У B `l1` и `l3` — профиль, `l2` — вспомогательная ось, единственная свободная степень эскиза — положение дальнего конца этой оси. Файл содержит профили; правило живёт в библиотеке проекта и назначается при добавлении лофта.
- [x] Контракт результата: три плоские треугольные фасеты (средняя — начало A, конец A, апекс — лежит в плоскости A; два крыла — конец A, апекс, конец B) и два цилиндрических гиба по линиям апекс→концы A с радиусом правила (не острые, D181) и K-фактором правила для развёртки.
- [x] Торец гиба у ребра A — квадратный срез толщины (гиб выходит на боковое ребро; ступень на углу автор подтвердил); толщина на стороне листа (`left`/`right`/`middle`), как в шаге 1.
- [x] Развёртка — через `unfold_side`: плоский веер с двумя гибами; у открытого `1 → 2` нет отдельного шва.
- [x] B — номинальный профиль. Прямые участки — монтажные кромки под сварку или фланец. У вершины B допустим местный зазор до ответной детали: не требуется укладывать весь торец в плоскость B. Это не разрешение на щель в самом листе, автоматическую разгрузку или перехлёст заготовки (D266).

## Отказы

- [x] Апекс на линии A (у средней фасеты нет площади) → `Degenerate`.
- [x] Нога B на линии гиба (у крыла нет площади) → `Degenerate` (фасета нулевой площади).
- [x] Касательные двух гибов не сходятся в общей точке или станции выходят за шарниры → `Degenerate`.
- [x] Профили вне случая (дуги, больше двух сегментов) → `Unsupported` с текстом; апекс не над серединой A → `Degenerate` (тест `two_line_loft_requires_the_vertex_over_the_first_line_midpoint`).

## Геометрия и сборка

- [x] Планировка `two_bend_layout`: углы сгибов, радиусы inner/outer/neutral, смещения касательных, центры, общие станции угла.
- [x] Кожи `two_bend_geom`/`BendSkin`: точки обеих кож, оси гибов `a0→vertex`/`a1→vertex`, цилиндры с дугами; у offset-кожи гребень ≠ сдвинутая вершина, крылья подрезаются гребнем (точка R = ridge ∩ дальнее ребро), у апекса появляется полоска.
- [x] В черновике `two_bend_body` заданы средние фасеты, крылья, стенки, цилиндры с дугами и ступени; их текущие границы не образуют тело.
- [x] Разведены диагностический пробник (`body_builds_for_the_probe_case`, A = 20 мм) и эталон профилей автора (`A = 100`, ноги по `200`, отступ `300` мм). Числа эталона сверены по файлу и решённым эскизам, не по PNG.
- [x] Параметры эталона Datum: правило `08пс 2 мм` (материал `Тест`), `t = 2 мм`, `R = t = 2 мм`, `K = 0,44` подтверждён автором. В доступном экземпляре файла правила поле K отсутствовало; на временной копии с явным `k_factor: 0.44` команда `loft` прошла планировку: гибы по 20,254°, радиусы 2/4 мм, нейтральный 2,88 мм. `side: left` — базовый тест команды, `right/middle` — отдельные проверки. Тело по-прежнему не подключено (`Unsupported`); исходные файлы не менялись.
- [ ] Проверить стык B на эталоне: первым проверить вариант с двумя торцами гибов, сходящимися по общему ребру через толщину в точке встречи касательных на средней фасете. На B — одна непрерывная кромка, без прорези и без остаточных острых участков, которые не разворачиваются; прямые монтажные участки остаются на линиях своих фасет. Обе стороны получаются из одного контура на заготовке, а не двух независимо обрезанных кож. Ступень у A сохраняется. Если такой стык не получается, не подгонять допуск и не вводить разгрузку молча.
- [ ] Перед `build_with_curves` проверить инцидентность: ровно две грани на каждое ребро, затем противоположные обходы и согласованность с поверхностями. Сейчас `NonManifold` возникает до `Body::validate()`; в дампе пробника на одном отрезке три грани (2/3/24), есть и непарные отрезки. Общие вершины и `TopoId` — по происхождению, не по близости координат или порядку сборки.
- [ ] На `left/right/middle` проверить обе стороны листа: одна замкнутая оболочка проходит `Body::validate()`, два гиба имеют по паре соосных цилиндров внутреннего и наружного радиусов с правильной ориентацией; плоские фасеты касательны к гибам, торцы замкнуты.
