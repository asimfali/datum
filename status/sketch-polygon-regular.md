## П.1 — связи регулярности в `plan()` (`crates/datum-view/src/polygon.rs`)

- [x] Окружность (замкнутый многоугольник): `n−1` связей `Equal` между соседними сторонами, DOF остаётся 1 (вращение), новых построительных линий не добавлено; драг вершины вращает многоугольник — тест `a_dragged_vertex_keeps_a_circle_polygon_regular`.
- [x] Дуга (открытая цепь): те же `n−1` `Equal` плюс `Coincident` первой вершины с точкой `from` дуги и последней с `to`; цепь жёсткая (0 DOF), при правке дуги равные шаги восстанавливаются сами — тесты `an_arc_chain_holds_still`, `an_arc_edited_puts_the_steps_equal_again`.

## П.2 — владение и перередактирование числа сторон

- [x] Многоугольник — группа эскиза `groups["polygonN"]` (точки, линии, имя кривой); имя группы стабильно: при перестройке перезаписывается, не удаляется.
- [x] Узнавание «это многоугольник» по составу группы: ровно одна `construction`-кривая, точки с `on`-связями на неё и линии между ними; число сторон = длина набора линий — тесты `other_groups_are_no_polygon`, `the_curve_becomes_construction_and_holds_the_vertices`.
- [x] Клик по бейджу группы многоугольника открывает форму с числом (прецедент — форма массива, `app.rs`); клик по бейджу обычной группы — прежнее поведение.
- [x] Смена числа — пересборка тем же кодом, что создание: старые элементы группы и связи, ссылающиеся на её точки, удаляются, новые ставятся, группа перезаписывается тем же именем (`reedit`) — тест `the_sides_change_through_the_group`.
- [x] Отказ, если на кривой уже есть многоугольник — тест `a_curve_holds_one_polygon`.
