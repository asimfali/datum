Ветка `feat/edge-fillet` от `main` после слияния этапа D294. Результат — отдельный PR с инструментом «Кромка» и его применением в `язык.json`.

## 1. Геометрия и операция детали

- [x] Выделить общий расчёт сопряжения двух прямых в локальной плоскости. Скругление строит касательную круговую дугу, симметричная фаска откладывает заданное расстояние вдоль обеих прямых. Один расчёт используют операция детали и штамп.
- [x] Добавить операцию детали по стабильной ссылке на прямое ребро. Первый случай — выпуклый угол профиля постоянного сечения, ребро вдоль нормали к профилю. Скругление даёт цилиндрический участок, фаска — плоскость. Сохранять ссылки на незатронутую геометрию и возвращать ошибку, если размер не помещается или выбранная геометрия выходит за пределы первого случая.
- [x] Добавить эталон детали и проверить оба режима, перестроение после правки размера, касательность, валидность тела и STEP.

## 2. Инструмент «Кромка» по образцу эскиза (D296)

- [x] Kernel: вход `faces` — набор плоских торцов одной операцией с одним размером (разворот торца в углы через `edge_finish_face` при каждом перестроении); общий резолвер `edge_finish_targets` для ядра и отрисовки ссылок; сцена хранит угловые рёбра каждого плоского торца (`finish_edges_of`).
- [x] Курсорный интерфейс создания вместо окна: подсказка и ряд пресетов у курсора (переиспользовать `preset_row`/`preset_step` по D283), Tab переключает скругление и фаску, стрелки выбирают пресет, размер набирается с клавиатуры, предпросмотр до щелчка. Размер и режим сохраняются между щелчками.
- [x] Выбор отделён от истории: клик устанавливает выбор без записи операции; Shift/Ctrl+клик переключает отдельное ребро. Выбор торца добавляет все допустимые углы, а исключения отдельных рёбер остаются снятыми.
- [x] Enter применяет успешный предпросмотр текущего выбора; наведённая цель используется только при пустом выборе. После Enter сменой размера/режима задают параметры следующего набора, повторное применение на том же теле использует последнюю подтверждённую операцию. Предпросмотр и выбор не меняют стабильные метаданные тела, меша и имени операции; при редактировании пикинг идёт по входному телу фичи.
- [x] Сохранены Tab для переключения режима, стрелки и пресеты, ввод размера, окно правки операции из дерева.

- [ ] Отложенные замечания ревью: (а) разворот торца в ядре перебирает все рёбра тела на каждую вершину контура — O(V·E); таблицу «вершина → прямые рёбра» строить один раз; теперь `edge_finish_caps` (ядро) вызывается сцены на каждую перестройку — приоритет вырос.
