# План: Loft, шаг 3 — один отрезок → три

## Эталон и форма

- [x] Эталон автора `loft(1 to 3 line)(3 stage).json`: A 100 мм, средний отрезок B 200 мм, боковые по 100 мм под 45°, расстояние между сечениями 300 мм.
- [x] В B явное совпадение p3–p6 замыкает один из стыков. Общий сборщик контуров читает три отрезка как одну открытую цепь (D268).
- [x] Разметка эталона: средний отрезок B и A образуют трапецию. Боковой отрезок B и ближайший конец A образуют треугольное крыло. Два общих боковых ребра трапеции задают оси гибов.

## Построение

- [x] Порядок цепи B определяется по явно совпадающим вершинам. Проверяются параллельность и компланарность A и среднего отрезка B. Случай с развёрнутым направлением отрезков проверен тестом.
- [x] Переиспользованы расчёт цилиндров, касательных и толщины из Loft‑2. У B отдельные квадратные торцы в обоих углах трапеции, среднюю монтажную кромку закрывает стенка. Если станции пересечения различаются, короткие ступени идут вдоль касательных (D269).
- [x] Подключено к `loft`. Ссылки сохраняются после правки размера и правила; прежние хеши совпали.

## Приёмка

- [x] Тело и обе развёртки проходят проверку для `left/right/middle`. В заготовке один контур и четыре ненулевые касательные, наложений нет. Проверены параллельные оси и изменения размеров.
- [x] Обычный фланец на прямой средней кромке B и вырез через наклонный гиб проходят после правки. В DXF ассоциативный вырез остаётся одной окружностью.
- [x] Добавлен эталон. Все прежние хеши совпали, `scripts/check.sh` прошёл с детерминизмом на 1/4/16 потоках.
