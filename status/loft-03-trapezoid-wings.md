# План: Loft, шаг 3 — один отрезок → три

## Эталон и форма

- [x] Эталон автора `loft(1 to 3 line)(3 stage).json`: A 100 мм, средний отрезок B 200 мм, боковые по 100 мм под 45°, расстояние между сечениями 300 мм.
- [x] В B явное совпадение p3–p6 замыкает один из стыков. Общий сборщик контуров читает три отрезка как одну открытую цепь (D268).
- [ ] Разметка эталона: средний отрезок B и A образуют трапецию. Боковой отрезок B и ближайший конец A образуют треугольное крыло. Два общих боковых ребра трапеции задают оси гибов.

## Построение

- [ ] Восстановить порядок цепи B по именованным вершинам с учётом совпадений. Проверить параллельность и компланарность A и среднего отрезка B, отказать для вырождения или неподдерживаемой разметки.
- [ ] Переиспользовать расчёт цилиндров, касательных и толщины из Loft‑2. У B проверить независимые торцы гибов в обоих углах трапеции. Среднюю монтажную кромку закрывает собственная стенка толщины. Проверить, что касательные помещаются на всех фасетах и кромка непрерывна.
- [ ] Подключить к той же команде `loft`, проверить стабильность ссылок при правке размера и правила. Сохранить хеши Loft‑1 и Loft‑2.

## Приёмка

- [ ] Проверить тело и общую развёртку на эталоне для трёх вариантов толщины. Проверить четыре касательные, один контур заготовки, отсутствие самопересечений и наложений.
- [ ] Проверить обычный фланец на прямой кромке B и сквозной вырез через гиб из эскиза развёртки.
- [ ] Добавить эталон, проверить детерминизм и запустить `scripts/check.sh`.
