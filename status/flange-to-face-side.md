# План: фланец до грани по боковой кромке — достройка полосы (D311)

> Кейс автора: `test11.json` (Windows: `C:\Users\Simanov\datum-demo\part\test11.json`) — лист
> и почти вертикальная пластина пересекаются под углом; фланец нужен на **боковой** кромке листа,
> стена — параллельно грани пластины на зазоре. Автор построил желаемый результат вручную
> эскизами (`sketch4` — полоса-трапеция от боковой кромки до линии гиба, `sketch5` — стена 20 мм
> на касании). Таймбокс этапа ~1,5–2 ч, при перерасходе — стоп и обсуждение.

## Решение (D311, подтверждено автором 2026-11-27)

- Линия гиба — та же, что в D305: пересечение плоскости наружной поверхности листа с плоскостью
  грани, смещённой на абсолютный `gap` (`gap = 0` — касание). Новое: она проходит **за боковой
  кромкой** (в кейсе: `w = −78.75 + 0.249·s`, т.е. 78.8→53.9 мм за кромкой ширины 0, наклон ~14°
  к кромке) — прежний отказ «зазор за кромкой» заменяется достройкой.
- **Полоса-достройка** («призма»): в плоскости листа, от боковой кромки до линии гиба; концы
  квадратно боковой кромке (подтверждено автором); внешний край — линия гиба. Форма — трапеция,
  косая линия гиба покрывается самой трапецией.
- Далее обычный гиб (машина D205/D229): радиус из правила листа, отступ касательной гиба от
  линии пересечения — как в D305 (`flush_recess(r, t, a)`).
- Стена — **параллельно грани на зазоре** (логика D305 сохранена); `height` — обязательный
  обычный ввод D205, квадратно листу (значение автора 20 — пример, не константа).
- Фланец объявляется на **боковой кромке** (длинной, вдоль пути) + `to_face { face, from, gap }`;
  сторона достройки и сторона поворота выводятся из грани.
- Отказы: грань в плоскости листа → `Degenerate`; неплоская грань → `Unsupported`; `angle ≠ 90°`,
  `height_along`, несколько кромок за раз, грань не с той стороны (линия гиба за противоположной
  боковой кромкой) → именованные. Случай «линия гиба в пределах торца» — прежний путь D305
  (test10 не должен измениться).
- Тело с гранью — вход фланца, не потребляется (как в D305).

## Этап 1. Ядро: разрешение боковой кромки и полоса-достройка

- [x] `flange.rs`: обобщить `dims_for_face`/`bend_to_face` на боковую кромку: линия гиба в
      координатах листа (вдоль пути × поперёк), случай «за боковой» → ширина полосы на концах
      кромки; отступ касательной гиба. Готово: `FaceBend::{line, wide, setbacks, strip}`, ветка
      `oblique`; угол косого гиба — из двугранного угла плоскостей (`sin a = |n − (n·up)·up|`).
- [x] Достройка полосы в плоскости листа (трапеция: боковая кромка → линия гиба, квадратные
      концы) до машины гибов; ID новых элементов — по происхождению. `extended` растит концы
      кромки по отдельности (линейно); при равных концах — прежняя геометрия D305 байт-в-байт.
- [x] Отказы по решению (именованные), тест-перезвонок test10 (прежний путь не тронут): линия
      через тело, за противоположной кромкой, «нет места для гиба»; тесты сверяются с независимой
      геометрической конструкцией (1e-9), стена ∥ грани (1e-16), зазор точный.

## Этап 3. Развёртка — пройдена, риск снят

- [x] Развёртка косого гиба строится: одна область из 6 линий без дуг, полоса-трапеция в заготовке
      (торцы `100 + ширина полосы` по `grow_at`), линии гиба косые (13.98°, пролёт `100/cos14°`),

      площадью плоской части + ленты гиба + стены. Обе стороны развёртки согласованы.

## Этапы 6–7. «Другая сторона» при дотягивании — готово

- [x] Решение автора: одна кнопка «⇄ Другая сторона» и в режиме дотягивания — перекладывает стену
      на другую сторону детали. Геометрия измерена: разворот стены на той же линии гиба кладёт
      слэб между плоскостью грани и листом (не за плоскость) — не то; другая сторона детали
      достигается противоположной параллельной гранью (линия гиба смещается на толщину детали).
- [x] Форма: ⇄ в reaches циклит грани тела с нормалью напротив (`faces_across`, порядок по
      смещению, ничья — по ID; пусто — disabled), `f.flip` не трогает; включение reaches сбрасывает
      унаследованный `flip`. В обычном режиме ⇄ — как было (D205). Ядро: `flip=true` в `to_face` —
      именованный отказ «сторона стены следует из грани»; `nearly_parallel` переиспользован видом.
- [x] Тесты: дальняя грань кейса автора — слэб стены совпадает со слэбом пластины (41 тест
      `flange_to_face`); view — цикл туда-обратно, disabled, сброс `flip` (468); mcp — edit на
      дальнюю грань строит (17). `check.sh` EXIT 0, эталонные хеши целы.
