# Метаданные эскиза — отдельный PR перед библиотечной штамповкой

Контракт D275–D277. Цель: автор сам размечает отрезки и дуги `Жалюзи2.json` в окне; агент видит и правит те же данные. Штамповку не реализуем.

## 1. Данные и команды

- [x] Метаданные хранятся в эскизе по имени его отрезка или дуги. Произвольные непустые ключи и JSON-значения сохраняются; пустые словари не записываются. При чтении старых файлов новое поле необязательно.
- [x] `query_metadata {name, elements?}` возвращает свойства указанных отрезков/дуг, а без `elements` — всех размеченных в эскизе. `edit_metadata {name, elements, set?, remove?}` ставит ключи из `set`, снимает ключи из `remove` у всех целей; `null` в `set` — значение, не команда удалить. Проверка всех целей и свойств до изменения; правка одна и отменяется целиком. В MCP обе команды доступны через `execute` и обнаруживаются через `list_commands`.
- [x] Переименование переносит запись, не меняя её значения. Удаление кривой снимает запись; зеркало переносит весь словарь даже при замене оригинала. Вшитый инструмент хранит значения. Исполнения хранят `set` и `remove` по свойствам, независимо наследуют остальные ключи, не оживляют метки при повторном имени удалённой кривой. Отдельно проверены первая метка в исполнении без меток у родителя и снятие последней унаследованной.
- [x] Метаданные не меняют хеши и вычисления геометрии. Регрессии проверяют `computed` и хеши эскиза, его потребителя и вшитого определения `component`; корпус эталонов не изменён. Роли пока не читаются операциями.

## 2. Настраиваемые пресеты

- [x] Один раздел `metadata_presets`: ID → `{label?, set: {ключ: JSON-значение}}`. `label` — текст или словарь по коду языка; если перевода нет — английский, затем ID. «Рез» и «Переход» — данные поставляемого JSON, не ветви кода.
- [x] Общий загрузчик окна и MCP (`list_metadata_presets`): поставляемые → общие → проект активной модели. Совпадающий ID заменяется целиком, `null` скрывает пресет. Ошибочные записи диагностируются, допустимые остаются доступны. Изменение настроек — через JSON.
- [x] Пресет заполняет `edit_metadata.set`, в модели остаются только значения. Тесты проверяют замену, скрытие и диагностику; отдельный прогон CLI/MCP подтвердил, что разметка открывается вне исходного проекта, с другим каталогом пресетов.

## 3. Окно

- [x] Настраиваемый F12 открывает редактор из эскиза. С выделением видны свойства выбранных отрезков и дуг; разные значения показаны как смешанные. Без выделения — список размеченных кривых, либо можно выделить кривые после открытия. Черновик не переназначается молча; Escape не применяет его.
- [x] В окне можно выбрать пресет или вручную задать, поменять и удалить ключ/значение. Одно применение — один вызов `edit_metadata` и один Undo. Тесты окна проверяют F12 с выделением и без, захват выделения после открытия, правку значения, применение пресета и отмену.
